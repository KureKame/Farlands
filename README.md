# Farlands (With GPU Chunk Selection Pass)

## Setup

Install [Minecraft](https://www.minecraft.net/en-us/about-minecraft), followed by [Fabric](https://fabricmc.net/use/installer/) version 0.19.3 for Minecraft version 26.2.

Add the jar to the `mods` folder inside `.minecraft` (usually found in `AppData/Roaming` on Windows). The Fabric API is also needed (version 0.153.0+26.2) which can be found [here](https://modrinth.com/mod/fabric-api/versions?g=26.2) and should also be put in the mods folder.

Upon first launching the game with the mod installed, ensure you update the video settings to make Vulkan the preferred graphics API and restart, otherwise the game will crash.
